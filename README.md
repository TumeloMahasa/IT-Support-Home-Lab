## Labs and Projects

### 1. Modern Computer Hardware Inspection

**Environments:** macOS and Ubuntu Linux  
**Tools:** macOS System Information, UTM, Ubuntu Terminal

This lab involved inspecting my MacBook Air's hardware information and investigating the resources visible to an Ubuntu virtual machine.

Linux commands used:

- `lscpu` — inspect CPU architecture and processor information.
- `free -h` — inspect memory and swap usage.
- `lsblk` — list block devices and partitions.
- `df -h /` — inspect root filesystem capacity and usage.

The exercise helped me understand the difference between physical host hardware, virtual machine resources, and filesystem usage.

**Documentation and evidence:** See [`01-Modern-Computer-Hardware`](01-Modern-Computer-Hardware/).
